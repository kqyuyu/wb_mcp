## Environment Variables

- `WB_API_KEY` - Your Wildberries API key (required)
- `WB_CONFIRM_WRITE` - Set to "1" to enable write operations (optional, default: 0)
- `WB_SANDBOX` - Set to "1" to use sandbox environment (optional, default: 0)
